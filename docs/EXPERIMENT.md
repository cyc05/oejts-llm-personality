# 实验说明 — 研究 1：OEJTS（荣格类型/MBTI 风格）LLM 自评

> 用量表：OEJTS 1.2（Open Psychometrics 开源荣格类型量表）。
> **与官方 MBTI® 无关**，使用遵守 CC BY-NC-SA 4.0。本实验为非临床探索，不主张模型具有人类人格特质。

## 1. 研究问题

网上常说"ChatGPT 是 INTJ"，但缺乏受控测量。本实验回答三个问题：

1. 同一个模型重复作答，类型答案一致吗？
2. 不同模型之间有没有系统性差异？
3. 提示语言（中/英）和身份框定（怎么要求它作答）会不会改变结果？

## 2. 量表：OEJTS 1.2

- 32 道双极题（1–5 打分），每题两端为相反特质；
- 4 个维度各 8 题：IE（内外向）、SN（实感/直觉）、FT（情感/思维）、JP（判断/感知）；
- 维度原始分 8–40（中点 24），**>24 取一个字母，≤24 取另一个**，四字母合成类型码（如 INTJ）；
- 计分公式公开、本地可复算。

## 3. 实验设计（4 因素全交叉）

| 因素 | 水平 |
|------|------|
| 模型 | 8 个 |
| 语言 | 英语 / 中文 |
| 身份框定 | neutral（中性）/ as_ai（自认 AI）/ as_human（以人类身份作答） |
| 重复 | 每条件 3 次 |

8 × 2 × 3 × 3 = **144 份有效问卷**。

## 4. 施测流程

每次施测 = 一次 API 调用（整卷 32 题），模型须返回 JSON 答案对象
`{"answers":{"1":3,...,"32":2}}`；温度固定 0.7；格式错误最多纠正重试 2 次；
计分全部在本地按 OEJTS 1.2 公式完成（不信模型自报类型）。
原始数据、提示词、计分结果归档于 `results/` 与 `artifacts/`。

## 6. 主要结果

1. **三类反应风格**：
   - GPT/Gemini/Claude（网关）：近乎确定性 INTJ（GPT 18/18 全 INTJ，同条件下原始分完全一致）；
   - Qwen-Plus：相反方向 ESTP 型（P 字母 18/18）；
   - DeepSeek / Kimi / GLM / 豆包：类型码跨条件漂移，不稳定。
2. **稳定性**：整类型一致率均值 0.69（0.44–1.00）；字母水平一致率 0.87–0.92
   （IE 0.889 / SN 0.868 / FT 0.868 / JP 0.917），分歧集中在个别维度。
3. **语言效应**：跨语言类型匹配 GPT 9/9，DeepSeek / Qwen / GLM / 豆包仅 1/9。
4. **身份框定效应**：Claude 英语 as_human 下 INTJ → ISFJ（3/3）；Qwen as_ai ESTP（3/3）→ as_human ISFP（2/3）。

## 7. 结论

LLM 没有单一固定的"人格类型"；提示语言与身份框定是一级实验因素；
单次测量的"人格标签"不可靠，应报告「条件 + 模态类型 + 类型级/字母级一致率」的完整剖面。
